# SDx-PreviousVer
Script to extend capabilities for reviewing engineer when viewing documents for review


Adds a button whenever a document for review is opened. 

<img width="3626" height="1935" alt="image" src="https://github.com/user-attachments/assets/b03a8886-502c-419d-9532-a47da488756f" />

When opened, the script will auto detect metadata of the document and create search terms for a background search for that document. 
User clicks "Find previous versions"

<img width="938" height="734" alt="image" src="https://github.com/user-attachments/assets/09853274-228b-4980-b0bf-5084075a951d" />


If the document was previously reviewed and a consolidated rendition exists, those will be surfaced to the top of the list, otherwise, the 
user will be presented links to the document history (where comments are not shown)

<img width="941" height="1637" alt="image" src="https://github.com/user-attachments/assets/16f404d4-eefe-4ce5-a62b-95c87e6e5e36" />


User can click the "Open consolidated pdf" and be directly taken to the previous version with comments.
